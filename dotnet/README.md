# LexFloatClient .NET Examples

Examples demonstrating floating license acquisition with the LexFloatClient .NET
library.

This directory contains three samples:

- [csharp-dotnet-core](csharp-dotnet-core/Program.cs) — cross-platform console (.NET 6)
- [csharp-dotnet-45](csharp-dotnet-45/Form1.cs) — Windows WinForms (.NET Framework 4.5)
- [vb-dotnet-45](vb-dotnet-45/Form1.vb) — Windows WinForms, VB.NET (.NET Framework 4.5)

## Running

### csharp-dotnet-core (cross-platform, .NET 6)

```bash
cd dotnet/csharp-dotnet-core
dotnet run
```

### csharp-dotnet-45 / vb-dotnet-45 (Windows, .NET Framework 4.5)

Open the `.sln` in Visual Studio, restore NuGet packages, and run.

Set your product ID and float server URL in the sample source before running.
