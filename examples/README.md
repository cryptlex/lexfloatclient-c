# LexFloatClient JS Example

Example demonstrating floating license acquisition with the LexFloatClient
Node.js library.

## Running

This directory contains a console sample:

- [sample.js](sample.js) — console sample

```bash
cd examples
npm install
node sample.js
```

Set your product ID and float server URL in `sample.js` before running.
