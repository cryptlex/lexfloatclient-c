# LexFloatClient Java Example

Example demonstrating floating license acquisition with the LexFloatClient Java
library.

## Running

This directory contains a console sample:

- [FloatSample.java](floatsample/src/main/java/com/cryptlex/floatsample/FloatSample.java) — console sample

```bash
cd examples/floatsample
mvn compile exec:java
```

Set your product ID and float server URL in `FloatSample.java` before running.
