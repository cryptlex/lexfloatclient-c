# LexFloatClient Go Example

Example demonstrating floating license acquisition with the LexFloatClient Go
library.

## Running

This directory contains a console sample:

- [sample.go](sample.go) — console sample

```bash
cd go
go run .
```

Set your product ID and float server URL in `sample.go` before running.
